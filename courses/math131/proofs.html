Proofs

The basics of number theory are often used to introduce proof-writing. These problems are difficult because they're not particularly algorithmic: each proof looks different, and there's a less-clearly defined "set of steps" to write a proof.

Generally, solving a problem involves asking two questions: "What do I know?" and "What do I want to know?" Most statements that one will be asked to prove are conditional statements of the form \[\text{If } p, \text{ then } q\] So, \(p\) is what you know, \(q\) is what you want to know, and your task is to bridge the gap between these statements.

Almost always, the first step after laying out this information will be to use the definition(s) of the objects involved. We will focus our attention on 3 simple definitions:

Definition of divisibility: Given integers \(a\) and \(b\), we say \(a\) divides \(b\) (or \(b\) is divisible by \(a\)) if and only if \(b = ak\) for some integer \(k\).

That is, \(a\) "goes into" \(b\) if we can write \(b\) as \(a\) times some other integer.

Definition of even: An integer \(x\) is even if and only if \(x = 2k\) for some integer \(k\).

Definition of odd: An integer \(x\) is odd if and only if \(x = 2k+1\) for some integer \(k\).

That is, \(x\) is even if it can be written as 2 times some integer, or odd if it can be written as 2 times some integer, plus one.

Statements can also be quantified. By this, we mean the words "all/every" (called the universal quantifier \(\forall\)) or "some/there exists" (called the existential quantifier, \(\exists\)). Proving a universal statement entails proving that something is true in general, whereas proving an existential statement requires you only to come up with an example. When disproving these statements, the situation is reversed. See below a table summarizing the possibilities (we will follow it with some examples):

Proving/disproving quantified statements: \[ \begin{array}{|c|cc|} \hline & \text{Universal Statement} & \text{Existential Statement} \\ \hline \text{Prove} & \text{General proof} & \text{Find an example} \\ \text{Disprove} & \text{Find a counterexample} & \text{General disproof} \\ \hline \end{array} \]

\[\text{Question 1: Prove or disprove: There exists an integer which is divisible by 7.}\] We are in the right-hand column of the above table, since this is a statement that something exists. To prove it, we would need to find an example of such an integer, which is divisible by 7. To disprove it, we would need to show that no matter what integer we pick, it is not divisible by 7. We first need to decide: do we think the statement is true (in which case we'll try to prove it) or false (in which case we'll try to disprove it). In this case, it's fairly obvious: of course we can come up with at least one example of an integer divisible by 7 (say 14, since \(14 = 7 \cdot 2\), or even 7 itself, since \(7 = 7 \cdot 1\)), and by giving such an example we have proven the statement true.

\[\text{Question 2: Prove or disprove: If \(x\) is odd, then \(3x + 7\) is even.}\] We are in the left-hand column of the table, since this is a statement that something is true in general. To prove it, we would need to show that for an arbitrary odd integer (we can't use a specific integer), that if we multiply it by 3 and then add 7, we get an even integer. To disprove it, we would need to come up with a counterexample: a specific integer which is odd such that when we multiply it by 3 and then add 7, we don't get an even result. Once again, we need to start by deciding whether or not the statement is true.

To make this decision, a good starting point is try out some examples. We try a few odd numbers for \(x\). If \(x = 5\), then \(3x+7 = 15+7 = 22\), which is even. If \(x = 7\), then \(3x+7 = 21 + 7 = 28\). If we keep trying, we keep finding that the statement holds, so we are convinced that it may be true (but no matter how many examples we come up with, we still haven't proven the statement is true in general). To prove the statement, we will have to start with the general form of what we know: \[\text{Let }x \text{ be an arbitrary odd number.}\] Generally, the next step is to use the definition: \[\text{Since } x \text{ is odd, } x = 2k+1 \text{ for some integer }k.\] Our end goal is to show that \(3x + 7\) is even. So, we will need to show that it's equal to 2 times an integer. With our target in mind, let's take a look at \(3x + 7\), and use what we now know \(x\) is equal to: \[3x + 7 = 3(2k + 1) + 7\] Then, let's use some algebra to hopefully turn what we have into the form we want (2 times an integer): \[= 6k + 3 + 7 = 6k + 10 = 2(3k + 5)\] And since the integers are closed under addition and multiplication, and 3, \(k\), and 5 are all integers, \(3k+5\) is an integer. So we've expressed \(3x+7\) as the product of 2 and an integer, and have successfully proven it is even.

Note that using the definition isn't the only way to prove a universal statement. If we happen to know certain facts are true in general about the objects in our problem, we can use those facts to complete the proof. In the previous problem, given our arbitrary odd integer \(x\), since we know that 3 is odd, and the product of two odd numbers is itself odd, we conclude \(3x\) is odd. Then, since \(3x\) is odd and 7 is odd, and we know that the sum of two odd numbers is itself even, we conclude \(3x +7\) is even, and are done.

\[\text{Question 3: Prove or disprove: If \(x\) is even, then \(4x\) is divisible by 16.}\] We are in the left-hand column of the table, since this is a statement that something is true in general. To prove it, we would need to show that for an arbitrary even integer (we can't use a specific integer), that if we multiply it by 4, the result is divisible by 16. To disprove it, we would need to come up with a counterexample: a specific integer which is even such that when we multiply it by 4, we don't get a number which is divisible by 16. Once again, we need to start by deciding whether or not the statement is true. We try some examples of even numbers \(x\): \[\text{If }x = 4, \text{ then }4x = 4 \cdot 4 = 16 = 16 \cdot 1\] \[\text{If }x = 8, \text{ then }4x = 4 \cdot 8 = 32 = 16 \cdot 2\] So far, the statement has held true. \[\text{If }x = 6, \text{ then }4x = 4 \cdot 6 = 24 = 16 \cdot 1.5\] so we have found a counterexample, and have disproven the statement.

\[\text{Question 4: Prove or disprove: There exists an odd integer whose square is even. }\] We are in the right-hand column of the table, since this is a statement that something exists. To prove it, we would need to find some specific odd integer whose square is even. To disprove it, we would need to show that the statement is not true in general. That is, we would show that for an arbitrary odd integer, its square is never even. Once again, we need to start by deciding whether or not the statement is true. We try some examples of odd numbers \(x\): \[\text{If }x = 5, \text{ then }5^2 = 25, \text{ which is odd.}\] \[\text{If }x = 9, \text{ then }9^2 = 81, \text{ which is odd.}\] If we keep trying odd numbers, the statement continues to be false, so we suspect it is false, and attempt to disprove it. So, we must use the definition to disprove it in general. To disprove the statement, we will have to start with the general form of what we know: \[\text{Let }x \text{ be an arbitrary odd number.}\] Then we use the definition: \[\text{Since } x \text{ is odd, } x = 2k+1 \text{ for some integer }k.\] Our end goal is to show that \(x^2\) is not even. Since every integer is either even or odd, this is equivalent to showing that \(x^2\) is odd. So, we will need to show that it's equal to 2 times an integer, plus 1. With our target in mind, let's take a look at \(x^2\), and use what we now know \(x\) is equal to: \[x^2 = (2k+1)^2\] Then, let's use some algebra to hopefully turn what we have into the form we want (2 times an integer plus 1): \[= (2k+1)(2k+1) = 4k^2 + 2k + 2k + 1 = 4k^2 + 4k + 1 = 2(2k^2 + 2k) + 1\] And since the integers are closed under addition and multiplication, \(2k^2 + 2k\) is an integer. So we've expressed \(x^2\) as the product of 2 and an integer, plus 1, and have successfully disproven the statement.

Finally, we'll conclude with 2 more complicated problems. The first is one where our usual "forward" method of proof doesn't work (and we'll have to reverse things by proving the contrapositive statement of the original), and the second is a word problem where we'll have to assign variable names to the unknown quantities involved before rephrasing the problem as a statement in terms of the definitions we know.

\[\text{Question 5: Prove or disprove: If \(5x-2\) is odd, then \(x\) is odd.}\] We are in the left-hand column of the table, since this is a statement that something is true in general. To prove it, we would need to show that for an arbitrary odd integer \(5x-2\) (we can't use a specific expression), that \(x\) must be odd. After some experimentation (as before), you could convince yourself that this statement is probably true, and set out to prove it. Your instinct is probably to let \(x\) be an arbitary odd integer, and then use the definition to show that \(5x-2\) is odd.

However, this would be incorrect. You would be showing that \[\text{If } x \text{ is odd, then } 5x-2 \text{ is odd.}\] which is not equivalent to the original statement. Your next attempt might be to start with the general form of what we know: \[\text{Let }5x-2 \text{ be an arbitrary odd number.}\] Then, use the definition: \[\text{Since } 5x-2 \text{ is odd, } 5x-2 = 2k+1 \text{ for some integer }k.\] Our goal is to show that \(x\) is odd: that is, to express it as 2 times an integer, plus 1. Keeping this destination in mind, we try to obtain \(x\) from what we have: \[5x - 2 = 2k + 1 \implies 5x = 2k + 3 \implies x = \frac{2k + 3}{5}\] There is no clear path forward here. In this problem, we will need to use the contrapositive version of the original statement to prove it: \[\text{If \(5x-2\) is odd, then \(x\) is odd.}\] is equivalent to the statement \[\text{If \(x\) is not odd, then \(5x-2\) is not odd.}\] That is, the statement \[\text{If \(x\) is even, then \(5x-2\) is even.}\] This is far easier to solve: we proceed as usual. \[\text{Let }x \text{ be an arbitrary even number.}\] Then, use the definition: \[\text{Since } x \text{ is even, } x = 2k \text{ for some integer }k.\] Our goal is to show that \(5x-2\) is even: that is, to express it as 2 times an integer. With our target in mind, let's take a look at \(5x-2\), and use what we now know \(x\) is equal to: \[5x -2 = 5(2k) -2\] Then, let's use some algebra to hopefully turn what we have into the form we want (2 times an integer): \[= 10k -2 = 2(5k-1)\] And since the integers are closed under addition and multiplication, \(5k-1\) is an integer. So we've expressed \(5x-2\) as the product of 2 and an integer, and have successfully proven it is even. So since we've proven the contrapositive statement, which is equivalent to the original, we've successfully proven the original statement.

When should you use the contrapositive? As a general "rule of thumb", when proving a statement of the form "If \(p\), then \(q\)", it tends to be easier to work forward from a simple statement rather than a "messy" one. So if \(p\) is messier/more complicated than \(q\), it is a good sign that the contrapositive may be a more fruitful avenue.

\[\text{Question 6: If you can evenly share 7 boxes of chocolates or 5 boxes of chocolates evenly with your friends,}\] \[\text{can you share one box of chocolates evenly with them?}\] Our first step is to identify quantities we don't know, and assign variables to them. We don't know how many chocolates are in each box, so \[\text{Let } x \text{ be the number of chocolates in each box.}\] and we also don't know how many friends you have, so \[\text{Let } y \text{ be the number of friends you have.}\] The next step is to convert the word problem into a "mathematical statement". An expression which should cue us is "evenly share": that is, we're dividing the chocolates up evenly among the friends. In other words, the number of chocolates in 7 boxes is evenly divisible by the number of friends \(y\), and so is the number of chocolates in 5 boxes. This is what we know. What we want to know is that the number of chocolates in 1 box is evenly divisible by \(y\). Converting this into an "if-then" statement, we are asked \[\text{Prove or disprove: If } y\mid 7x \text{ and } y\mid 5x, \text{ then } y\mid x\] We leave the experimentation process to the reader, which should convince you that the statement is true. So, we try to prove it. We start with what we know: \[\text{Let } x \text{ and } y \text{ be arbitary integers such that } y\mid 7x \text{ and } y\mid 5x.\] Then we use the definition of divisibility: \[\text{Since } y\mid 7x, 7x = yk \text{ for some integer \(k\), and since } y\mid 5x, 5x = yl \text{ for some integer \(l\).}\] We keep our goal in mind: we want to show that \(x\) is divisible by \(y\), that is, we want to express \(x\) as the product of \(y\) and some integer. This problem is a bit more on the challenging side: we'll need to express \(x\) in terms of the things we know. Some options would be to divide \(7x\) by 7, or \(5x\) by 5. However, from experience (of a divisibility theorem we've learned), it would be most useful to express \(x\) as a linear combination of the things we know (that is, a sum/difference of multiplies of what we know). It might take some playing around to discover how we can do this: \[x = 3(7x) - 4(5x)\] Then, we substitute our known expression for \(7x\) and \(5x\), and attempt to factor \(y\) out of the result: \[= 3yk - 4yl = y(3k - 4l)\] Since the integers are closed under multiplication and subtraction, \(3k-4l\) is an integer, and so we've expressed \(x\) as the product of \(y\) and an integer, so \(x\) is divisible by \(y\), and we conclude that it is possible to evenly share one box of chocolates with your friends.
